Plugins-Admin-ready packaging.

## New in 1.3.1

* **The plugin package now fits the official plugin list.** `PersianKit.dll` sits at the **root** of
  `PersianKit_x64.zip` / `PersianKit_x86.zip` - the layout `Plugins Admin` extracts into
  `plugins\PersianKit\`. The previous packages nested it as `x64\PersianKit\PersianKit.dll`, which the
  list's CI rejects (`Zip file does not contain PersianKit.dll`) and which would have installed to
  `plugins\x64\PersianKit\` (see [nppPluginList#1272](https://github.com/notepad-plus-plus/nppPluginList/pull/1272)).
* **The DLL finally carries a version.** A VERSIONINFO resource (1.3.1.0, taken from `src/version.h`) is
  compiled into both binaries: Explorer shows it, `About` prints it, and the plugin list can compare it
  with the entry's version. Without it the list's CI answers `Does not contain any version information.`
* `build\package.ps1` builds the release packages (root-level DLL, plus the kit zip) and prints their
  SHA-256; `build\test\verify-package.ps1` replays the list validator's rules offline.
* CI now builds both architectures, verifies the packages and publishes this release; the tag has to match
  `src/version.h`.
* The plugin itself behaves exactly as 1.3.0 - no command, shortcut or ini key changed.

## Assets

* `PersianKit_x64.zip` / `PersianKit_x86.zip` - the plugin. Create `<Notepad++>\plugins\PersianKit\` and put
  `PersianKit.dll` in it (Plugins Admin does this by itself once the plugin list ships), restart Notepad++.
* `NotepadPlusPlus-Persian-Kit.zip` - the optional kit: Vazirmatn font, DirectWrite off, word wrap, JSON
  colours, RTL Markdown-preview CSS. Unchanged.

## RTL checklist

1. DirectWrite off (`Settings > Preferences > MISC`) + restart
2. UTF-8 document
3. Vazirmatn installed
